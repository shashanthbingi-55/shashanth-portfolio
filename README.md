# Shashanth - Personal Portfolio

A responsive personal portfolio website built with HTML5, CSS3 and JavaScript.

## Files
- `index.html` - page content and structure
- `style.css` - layout, colors and responsive styling
- `script.js` - mobile navigation and current year

## Before publishing
1. Open `index.html` in a browser or use VS Code Live Server.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email address.
3. Check that the skills and description accurately reflect your abilities.
4. Add only real projects you have completed.

## GitHub Pages
Upload all files and folders to the root of a public GitHub repository. Then open:
Settings -> Pages -> Deploy from a branch -> `main` -> `/ (root)` -> Save.

Your site will be available at:
`https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/`
